CH_Glide

Outputs a control signal as Lua control "CHG". A tablet reads the corresponding servo channel on the EX Bus and switches pages and functions accordingly.

Items and default values

  • Start/Restart: +80 %, pulse 2.0 s
  • Thermal page: −60 %, hold
  • Glide page: −40 %, hold
  • Start page: −80 %, hold
  • Info page: −100 %, hold
  • Mute vario: +20 %, hold
  • Navbox value announcement 1 / 2 / 3: +40 / +50 / +60 %, pulse 1.0 s
  • no item active: 0 %; error in the app: +100 %

Hold: the value is present while the switch is on. Pulse: the value is sent for the set duration (0.5…10 s) when the switch is turned on. A running pulse has priority; otherwise the most recently switched-on hold item wins. Heartbeat: the value changes by 1 % every other second.

Setup

  • Applications › CH_Glide: set switch, value (−100…+100 %), type and duration for each item. The detail page shows the live switch state at the bottom.
  • Functions assignment: create a function, control = Lua control "CHG CH_Glide".
  • Servo assignment: put the function on the channel the tablet reads.
  • Neutral servo settings: center 0, travel ±100 %, no curve/expo/delay.

The app menu is in German. Changed values must also be updated on the tablet.

Use at your own risk; do not control critical functions with Lua apps.
